# Task 4 - Firewall Configuration

## Objective
Configure and test basic firewall rules to allow or block traffic.

## Tool Used
Windows Defender Firewall with Advanced Security

## Steps Performed

1. Opened Windows Firewall.
2. Viewed existing inbound rules.
3. Created a new inbound rule blocking TCP Port 23 (Telnet).
4. Verified the rule was active.
5. Created an allow rule for TCP Port 22.
6. Removed the test rule after verification.

## Outcome

Learned basic firewall management and network traffic filtering using Windows Firewall.
